### arkd (1 commit)
- **API / public-surface**: New `AdminService.GetSettings` / `UpdateSettings` gRPC + REST endpoints (`GET`/`POST /v1/admin/settings`) with a 21-field `Settings` message and `update_fields`-based partial updates; new macaroon permissions added for both (`3334279` by Bob Smith)
- **Breaking (ops/config)**: Settings env vars removed from `internal/config` — values are seeded from env only on first boot, then live in the DB as source of truth; `docker-compose.regtest.yml` updated accordingly (`3334279`)
- **Schema migration**: New `settings` table in both Postgres (`20260609120126_add_settings`) and SQLite (`20260609120123_add_settings`), plus badger and redis/in-memory live-store settings repos (`3334279`)
- **Behavior change — runtime-mutable params**: Round min/max participants, exit delays (unilateral/checkpoint/boarding), VTXO tree expiry, vtxo/utxo min/max amounts, max tx weight, ban threshold/duration are now admin-mutable at runtime without restart — clients caching `GetInfo` should track the `digest` field (`3334279`)
- **API / GetInfo internals**: `GetInfo` digest is no longer computed per-request in the gRPC handler (sha256 of marshaled response); it now comes from the app layer (`info.Digest`), and `info_cache.go` was removed — digest values may differ from before even with identical config (`3334279`)
- **pkg/ark-lib (additive exports)**: New `ParseRelativeLocktime(uint32)` and `MinAllowedSequence = 512` in `locktime.go`; `arkfee.Estimator.New` now wraps CEL parse errors with context (`3334279`)

### Cross-cutting
- arkd → go-sdk: `admin.proto` gained `Settings`/`GetSettings`/`UpdateSettings` — go-sdk's generated admin client needs regeneration to expose them; `ark.proto` client surface is unchanged, and the `pkg/ark-lib` locktime additions are additive (safe bump)
- fulmine/introspector: server params fulmine reads via `GetInfo` (exit delays, amount limits, round participant bounds) can now change mid-session via admin API — any startup-time caching of these values should re-validate on `digest` change
