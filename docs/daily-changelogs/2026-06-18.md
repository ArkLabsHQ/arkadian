## Highlights for your stack

### arkd (1 commits)
- **API / public-surface**: new `types.DeprecatedSigner` struct + `Config.DeprecatedSigners` field, and new `Config.AllSigners()` method (returns active signer + all deprecated signers keyed by x-only hex) (`268d19d9` by Dusan Sekulic)
- **Signing / verification logic**: offchain tx verification now accepts signatures from *any* configured signer (active or deprecated, until each one's `CutoffDate`) — `verifySignedArk`/`verifySignedCheckpoints`/`verifyOffchainPsbt` switched from a single `*btcec.PublicKey` to a `map[string]*btcec.PublicKey`. Enables signer-key rotation without breaking client-side verification on `SendOffChain`, `IssueAsset`, `ReissueAsset`, `BurnAsset` (`268d19d9` by Dusan Sekulic)
- **Schema / persistence**: file config store gains a `deprecated_signers` field (`pubkey` + RFC3339 `cutoff_date`) in `storeData`, written by `AddData` and restored in `decode()`/`asMap()` — old config files decode fine (empty slice), but configs written by this version add the new key (`268d19d9` by Dusan Sekulic)

### Cross-cutting
- arkd → go-sdk: all changes are in `pkg/client-lib/` (the surface go-sdk/fulmine consume). Action: when verifying server-signed txs, source signer keys via `Config.AllSigners()` rather than `SignerPubKey` alone, or you'll reject valid sigs during a signer rotation window. `SignerPubKey` remains present and unchanged.
