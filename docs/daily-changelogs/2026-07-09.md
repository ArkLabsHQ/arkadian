### arkd (4 commits)

- **Breaking (port interface)**: `TxBuilder.BuildCommitmentTx` signature changed — now takes `vtxoTreeExpiry arklib.RelativeLocktime` as a param instead of via the constructor, so live config changes aren't missed (`89ddbf61` by Pietralberto Mazza). Only matters if you implement/mock this port, but worth noting.
- **API / structured errors**: New indexer gRPC errors `TX_FILTERS_LIMIT_EXCEEDED` (code 51, InvalidArgument, w/ `max_tx_filters`/`got_tx_filters` metadata) and `INVALID_TX_FILTER` (code 52, InvalidArgument, w/ `expression`) — clients hitting `GetSubscription`/tx-filter limits now get typed errors instead of generic ones (`0cb5f8e9` by Bob Smith).
- **Indexer subscription/streaming**: `GetSubscription` reworked — reconnecting with the same subscription id now *displaces* the old stream (exclusive listener attachment), displaced streams terminate instead of stealing events, and failed attaches no longer leak listeners. Directly relevant to your subscription-amplification / 429 concerns from [[project_inc1_429_streaming]] (`5c56d54c` by Andrew Camilleri).
- **New feature (gRPC keepalive)**: Server now pings clients (`Time: 30s`, `Timeout: 20s`) and closes dead connections; a `keepAlive` gRPC option was added on the indexer path (`5c56d54c` by Andrew Camilleri).
- **Removed surface**: Round report service dropped entirely — `RoundReportService()` config, `round_report.go`, and `telemetry/round_stats.go` gone; `InitOtelSDK` no longer takes the report service arg (`b2647c02` by Pietralberto Mazza).

### Cross-cutting

- **arkd → go-sdk**: Two client-facing changes to watch — (1) new typed indexer errors `TX_FILTERS_LIMIT_EXCEEDED`/`INVALID_TX_FILTER` on subscription/tx-filter calls (handle codes 51/52 in go-sdk + fulmine); (2) `GetSubscription` reconnect-displacement + server keepalive semantics change how long-lived indexer streams behave under reconnect — verify introspector/fulmine reconnect logic tolerates being displaced and the 30s/20s keepalive.
- **Port change is internal-only**: `BuildCommitmentTx` signature change lives in `internal/`, no proto/`pkg/client` impact — go-sdk unaffected unless you mirror the builder.
