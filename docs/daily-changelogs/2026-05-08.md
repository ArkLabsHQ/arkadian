### arkd (1 commit)
- **Breaking client-lib API**: `Explorer.GetUtxos(addr string)` → `GetUtxos(addresses []string)` — multi-address batched lookup with throttling to prevent rate limiting (`2999d666` by Pietralberto Mazza)

- **New public API**: `WithReceiver(addr)` cross-family option (`ReceiverOption` satisfies `SendOption` + `BatchSessionOption` + `UnrollOption`) — overrides change/destination address across `Send*`, `Settle`, `CollaborativeExit`, `Unroll`, `OnboardAgainAllExpiredBoardings`; with helpers `validateOffchainAddress` / `validateOnchainAddress` / `validateOffchainOrOnchainAddress` (`2999d666` by Pietralberto Mazza)
- **Internal cleanup**: removed exported-looking `balanceRes` (was unexported) from `types.go`; `funding.go`, `send.go`, `unroll.go`, `batch_session.go` reworked to consume the new receiver option (`2999d666` by Pietralberto Mazza)

### Cross-cutting
- arkd → go-sdk: `pkg/client-lib/` Explorer + WalletService interfaces changed shape — go-sdk consumers vendoring or implementing these (and fulmine via go-sdk) must update `GetUtxos` callers to pass `[]string`, and any custom wallet must implement `NextKeyId` + `GetKeyIndex` instead of `NextIndex`. Privacy note: `WithReceiver` skips `wallet.NewKey`, so reused change addresses won't be recorded in the wallet — relevant for fulmine/introspector accounting.
