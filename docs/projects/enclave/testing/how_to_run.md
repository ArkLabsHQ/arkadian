# How to Run

## Local Workflow

```sh
# 1. Install / build CLI
go install github.com/ArkLabsHQ/introspector-enclave/cli/cmd/enclave@latest
# OR build from source with hashes baked:
make build && make install

# 2. Scaffold (or validate) project
enclave init                          # adds enclave/ dir to existing repo
# or
enclave generate template --golang my-app   # full template

# 3. Compute Nix hashes from your git remote
enclave setup                         # Go (default), runs in Docker
enclave setup --language nodejs       # also rewrites enclave/flake.nix
enclave setup --language dotnet
enclave setup                 # use local Nix instead

# 4. (Optional) generate OpenTofu deployment scaffold
enclave tofu                          # writes ./tofu/ — merge-only-new
enclave tofu --remote                 # CI mode: pull artifacts from GitHub Release

# 5. Build EIF
enclave build              # Docker + Nix (reproducible)

# 6. Deploy
enclave deploy             # CDK: VPC, EC2, KMS, IAM, S3, secrets

# 7. Verify
enclave verify             # confirms attestation document + PCR0 match

# 8. Inspect
enclave status             # stack outputs, current PCR0, IP
```

## Update App

**Code-only:**

```sh
git push
enclave update
enclave build && enclave deploy
```

**Dependency changes:**

```sh
git push
enclave setup
enclave build && enclave deploy
```

## Lock the KMS Key (irreversible)

```sh
enclave lock
```

Removes admin access to the KMS key — only the attested PCR0 can decrypt. Future PCR0 changes require the migration flow.

## Tear Down

```sh
enclave destroy
```

> **Warning:** deletes the KMS key + S3 bucket. All secrets and storage data are permanently lost.

## Build the CLI from Source

```sh
make build         # builds ./enclave-cli with SDK hashes from cli/runtime-hashes.json baked in
make install       # installs to $GOPATH/bin
make lint          # golangci-lint across all modules (cli, runtime, supervisor, client)
```

## Build Docker Image (macOS / ARM)

The Makefile provides a multi-arch path for non-Linux builders:

```sh
make test-build-docker    # builds a linux/amd64 builder image and runs test-build inside it
```

## Production Deployment via GitHub Actions

Three scaffolded workflows (`.github/workflows/` in your app repo, generated by `enclave init`):

| Workflow | Trigger | Steps |
|----------|---------|-------|
| `deploy-enclave.yml` | manual | install CLI → pull Nix Docker image → `enclave build` → `enclave deploy` → publish `deployment.json` GitHub Release → GitHub artifact attestation → `enclave verify` (waits up to 5 min) → publish status page to `gh-pages` |
| `destroy-enclave.yml` | manual | install CLI → `enclave destroy --force` |
| `verify-enclave.yml` | daily 08:00 UTC + manual | download `deployment.json` from latest Release → `enclave verify` → update status page |

Required repository variables:

| Variable | Description |
|----------|-------------|
| `AWS_ROLE_ARN` | IAM role ARN with OIDC trust policy for this repo |
| `AWS_REGION` | AWS region (e.g. `us-east-1`) |

Required permissions: `id-token: write`, `contents: write`, `attestations: write`.

## Manual Verification

```sh
enclave verify --base-url https://<elastic-ip> --expected-pcr0 <pcr0>
gh attestation verify deployment.json --repo <owner>/<repo>
```

## Required Environment / Configuration

| Variable | Description |
|----------|-------------|
| `BOOT_TIMEOUT` (test) | Seconds to wait for QEMU boot (default 90, CI uses 120) |
| `INIT_TIMEOUT` (test) | Seconds to wait for enclave init (default 120, CI uses 300) |
| `HOST_TLS_PORT` (test) | Enclave TLS port on host (default 8443) |
| `RUNTIME_LOCAL_PATH` (test) | Local override for runtime source (Nix `local source`) |
| `SUPERVISOR_LOCAL_PATH` (test) | Local override for supervisor source |
| `APP_LOCAL_PATH` (test) | Local override for app source |
| `TF_VAR_env_values` (deploy) | JSON map of deploy-time env overrides |

## Operating the Live Enclave

Reach the host management API (loopback only) via SSM Session Manager:

```sh
# Health
curl http://127.0.0.1:8443/health

# Trigger locked-key migration (NDJSON stream)
curl -N -X POST http://127.0.0.1:8443/migrate

# Restart the enclave
curl -X POST http://127.0.0.1:8443/stop
curl -X POST http://127.0.0.1:8443/start
```

`enclave-supervisor.service` runs with `Restart=always`; the in-process watchdog restarts the enclave with bounded backoff (1s → 30s) when `nitro-cli describe-enclaves` shows it stopped.
