## Protocol surface — arkd → go-sdk

**Hotfix `42f58837` — "prevent failure on SubmitTx to affect finalization of pending tx" (#1063, Pietralberto Mazza)**
- Changed paths: `internal/core/application/service.go`, `internal/test/e2e/e2e_test.go`. **No `pkg/client/`, `api/`, `proto/`, or `internal/interface/grpc/` touched.**
- Behavior change: the `Fail`/event-save `defer` in `SubmitOffchainTx` is now scoped to run only after the offchain tx is created. Previously, early validation failures emitted a spurious `Fail` event on the stream that could affect finalization of unrelated pending txs.
- **Impact on go-sdk:** No proto / gRPC API change — go-sdk wrap surface unchanged. Behavioral: callers that submit invalid offchain txs will no longer see a phantom `Fail` event in the event stream; they will see only the original validation error. If go-sdk has assertions or logs around an expected `Fail` event on submit failure, those will need a quick sanity check.
