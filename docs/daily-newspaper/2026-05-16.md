Auto-settle / user-submit race producing `VTXO_ALREADY_SPENT`.** Arkana's slack-monitor flagged this as PROTOCOL-CRITICAL yesterday: when fulmine's auto-settle and a user-initiated submission both target the same VTXO, the loser sees `VTXO_ALREADY_SPENT`. Two of dusan's three sibling SDKs now have this; go-sdk doesn't. When go-sdk's contract-manager track is unblocked, this PR (plus dotnet-sdk's earlier version) is the prior art to mirror. The 9-test `walletHdRotation.test.ts` suite is a ready-made acceptance spec.

The new `src/test/e2e/bip21.test.ts` is the spec.
