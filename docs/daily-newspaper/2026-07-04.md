## Protocol surface — arkd → go-sdk

Two arkd commits landed (`af56a86 → ae56672`), both touching go-sdk's wrap surface.

- **BIP-322 intent-proof wire format changed** ⚠️ — `pkg/ark-lib/intent/proof.go`: `New()` now sets global `PSBT_GLOBAL_GENERIC_SIGNED_MESSAGE` (0x09) = UTF-8 message bytes, so a co-signer can recompute the `to_spend` commitment from PSBT-internal data alone and tell a genuine ownership proof from a fund-moving spend. Fixtures updated (`proof_test.go`).
  - `fc7f23ec` by afsheenb (#1132)
  - **Impact on go-sdk**: go-sdk vendors `ark-lib`; any code that builds *or* parses/verifies intent proofs must expect the new 0x09 field. Re-vendor `ark-lib` and refresh proof fixtures, or older-built proofs diverge from arkd's expected commitment. Same applies to fulmine/introspector.
- **CEL-based `batch_trigger` gate + admin field** — new `optional string batch_trigger = 26` on the admin `Settings` message (`admin.proto` + regen `admin.pb.go`); runtime-updatable via `UpdateSettings`, reported by `GetSettings`. New `add_batch_trigger` sqlite+postgres migrations.
  - `ae56672f` by Andrew Camilleri (#1046)
  - **Impact on go-sdk**: admin client bindings should regen to surface/set `batch_trigger` via `GetSettings`/`UpdateSettings`. Unset = legacy "always start" behavior, so it's non-breaking for existing callers.
