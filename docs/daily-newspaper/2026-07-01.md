## Protocol surface — arkd → go-sdk

- **Cursor-based pagination for `GetVtxoChain`** — `278bde6b` (Bob Smith, #1092). Adds `page_token` (req field 5) + `next_page_token` (resp field 4) to `indexer.proto`; cursor path ignores the legacy `page` struct, enforces a fixed max page size, rejects `intent + page_token` combos, and maps bad tokens to `InvalidArgument`. Auth-token TTL is now a hard ceiling (no keepalive/continuation fallback).
  - **Impact on go-sdk:** regen indexer client bindings. Fields are additive so existing callers compile, BUT any unpaged chain traversal (introspector, fulmine) now silently gets only the first page — you must loop on `next_page_token` to stay complete. Also hardens `NewIndexerService` (fails fast on withheld/private exposure without a privkey; skips nil signer pubkeys).
- **Watch checkpoint scripts** — `01570cf0` (Chris Ricketts, #1129). Watches checkpoint scripts on each new offchain tx (restore/stop-watching supported; checkpoint fetch soft-fails by design). Adds `VtxoRepository.GetCheckpointTxsByVtxoPubKeys(ctx, pubkeys) ([]Tx, error)` across badger/postgres/sqlite (SQL filters `swept=false`, `stage_code=3`).
  - **Impact on go-sdk:** internal arkd repo/watcher plumbing — no direct wrap-surface change unless go-sdk mirrors the checkpoint-tx query.
