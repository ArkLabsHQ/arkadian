## Protocol surface — arkd → go-sdk

No changes under `pkg/client/`, `api/`, `proto/`, `internal/interface/` in 24h. One behaviorally-relevant change elsewhere:

- **Return accepted-or-finalized tx only in `indexer.GetVirtualTx` / `service.GetPendingTx`** — `SelectOffchainTx` rewritten to filter `stage_code IN (2,3)` instead of `fail_reason = ''` (sqlite + postgres). `51384c05` (louisinger, #1123). Files: `internal/infrastructure/db/{sqlite,postgres}/...`.
  - **Impact on go-sdk**: No proto/signature change, so no code change required — but the *response semantics* shifted. Any go-sdk (or fulmine) polling that assumes a tx is visible here before stage 2/3 (pre-acceptance) will now get nothing until it's accepted/finalized. Verify polling loops that watch pending txs.
