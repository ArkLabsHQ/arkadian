## Protocol surface — arkd → go-sdk

- **Indexer subscription displacement + gRPC keepalive** — `5c56d54c` (Andrew Camilleri). Touches `internal/interface/grpc/handlers/{broker,indexer}.go`, `service.go`. Reconnecting with the same subscription id now displaces the old stream (exclusive listener attach), displaced streams terminate instead of stealing events, failed attaches no longer leak listeners; server also pings clients (`Time: 30s`, `Timeout: 20s`) and closes dead connections.
  - **Impact on go-sdk**: verify go-sdk's / fulmine's long-lived indexer stream reconnect tolerates being displaced and doesn't fight the 30s/20s keepalive. Behavioral change, no proto break — but reconnect logic should be tested against it.
- **Typed tx-filter errors** — `0cb5f8e9` (Bob Smith, #1141). Touches `internal/interface/grpc/handlers/indexer.go`, `pkg/errors/errors.go`. New `TX_FILTERS_LIMIT_EXCEEDED` (code 51, `InvalidArgument`, metadata `max_tx_filters`/`got_tx_filters`) and `INVALID_TX_FILTER` (code 52, `InvalidArgument`, metadata `expression`).
  - **Impact on go-sdk**: handle codes 51/52 in go-sdk + fulmine on subscription/tx-filter paths; clients previously got generic errors here.
- **Round-report service removed** — `b2647c02` (Pietralberto Mazza, #1137). Drops `RoundReportService()` config, `round_report.go`, `telemetry/round_stats.go`; `InitOtelSDK` no longer takes the report-service arg.
  - **Impact on go-sdk**: none for wrap surface — internal telemetry only. Flag only if anything you run scraped the round-report/round-stats telemetry.
- **`BuildCommitmentTx` port signature change** — `89ddbf61` (Pietralberto Mazza, #1145, hotfix). Now takes `vtxoTreeExpiry arklib.RelativeLocktime` as a param instead of via the constructor.
  - **Impact on go-sdk**: internal-only (`internal/core/ports/tx_builder.go`), no proto/`pkg/client` impact — unaffected unless you mirror the builder.
