## Protocol surface — arkd → go-sdk

- **Snapshot listener topics in indexer dispatch loop to avoid map race** (`ac3b563`, Bob Smith, #1144). Fixes a fatal concurrent map iteration+write crash in `listenToTxEvents`; the dispatch loop now iterates a locked snapshot via `getTopics` while Subscribe/Update/Unsubscribe RPCs mutate topics. Adds a `-race` regression test. Touches only `internal/interface/grpc/handlers/indexer.go` (+test).
  - **Impact on go-sdk**: No wrap change — server-side hardening only, no proto/signature change, no client regen. But it matters to you: a go-sdk client holding an indexer subscription that fires Update/Unsubscribe under load could previously crash arkd. Worth knowing for any subscription-heavy flow.
