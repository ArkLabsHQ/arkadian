## Protocol surface — arkd → go-sdk

arkd master moved `7591e53 → 11cf2ba` (5 commits). Relevant to go-sdk's wrap surface:

- **Signer-key deprecation** (`57c72343`, louisinger) — **Breaking (ark-lib)**: `intent.Proof.FinalizeAndExtract(signer)` → variadic `FinalizeAndExtract(signers ...)`. New `signer/v1` surface: `GetDeprecatedPubkeys`, `GetInfo` returns `DeprecatedSigners`, `DeprecatedSigner{pubkey, cutoff_date}`.
  - **Impact on go-sdk**: callers compile under the old single-arg form but should be reviewed; client init should surface deprecated keys + cutoff dates so recoverable coins are handled.
- **client-lib version header** (`76ebb425` then `11cf2ba8`, Pietralberto Mazza) — **Breaking (client-lib)**: `NewClient(url)` → `NewClient(url, version)`; new `WithClientVersion(...)` ServiceOption; client emits optional `x-sdk-version`. (The `ClientVersion` package var added in `76ebb42` was removed in `11cf2ba` in favor of the option.)
  - **Impact on go-sdk**: `NewClient` signature change — every go-sdk client constructor needs the version arg or the option.
- **Stricter interceptor guards** (`57c72343` / `11cf2ba8`) — version + digest guards now reject a *provided* below-min `x-build-version` or mismatched `x-digest`, not only when `RequireHeader` is set.
  - **Impact on go-sdk**: set a valid build version on the client, or risk rejection once the server enables `RequireHeader`.
- **Sweep-connectors admin fix** (`2bd1202d`, louisinger) — fixes the admin endpoint, truncates sweep inputs when needed; `ports.Wallet` signature touched.
  - **Impact on go-sdk**: admin/internal path — affects nothing in go-sdk's normal call surface.
- **SQLite read/write pools** (`505c6018`, Chris Ricketts) — separate pinned read/write pools, interrupt handling; `GetAsset` now a plain query.
  - **Impact on go-sdk**: no API change; improves arkd read consistency under churn.
