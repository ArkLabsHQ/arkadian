- **Botanix Spiderchain shutdown** (Jun 10) — a Bitcoin L2 wound down after a year: tech worked, adoption didn't (users preferred wrapped BTC). Cautionary tale flagged for Ark.

### Most important — expanded
1. **go-sdk's stale-subscription gap.** ts-sdk's `e0fac07` (#600, Pietro Grandi) adapts the client to arkd's *new* stale-subscription error format, which shipped as part of the subscription-model rework the June-20 Slack thread flagged SDKs hadn't adopted. arkd is now returning the new format in prod (it's in v0.9.12's line), so go-sdk clients that still parse the old error shape can misclassify a stale subscription as an unknown error. This is the single most concrete parity action for dusan this week: port the ts-sdk fix to go-sdk.
2. **arkd v0.9.12 client-lib surface changes.** Three commits in this release touch things go-sdk wraps directly — the explorer `GetFeeRate` endpoint (#1134), `GetVtxoChain` cursor pagination (#1092), and BIP-322 intent PSBT encoding (#1132). Since the local go-sdk checkout is weeks stale (May 25) and was skipped by today's sync, dusan should re-sync and diff go-sdk's client-lib against v0.9.12 before assuming compatibility — the pagination and intent-encoding changes in particular can silently break behavior rather than error loudly.
