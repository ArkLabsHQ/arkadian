## Contract surface — introspector

Branch `feat/op-keccak256` (not yet on master):
- **`OP_KECCAK256` generalised to `OP_DIGEST`** (`4890039` extend to general OP_DIGEST; `90e7e66` simplify digest test — both msinkec). Opcode `0xc3` keeps its slot but now **pops a hash-type selector** off the stack: `[... data hash_type] -> [... digest]`, supporting SHA256(1), SHA1(2), RIPEMD160(3), Keccak256(4), SHA3-256(5). **Semantics change**: any Arkade Script that used the old single-arg keccak form must now push a selector; raw `0xc3` is no longer a bare keccak.
